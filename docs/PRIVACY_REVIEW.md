# 公开副本脱敏记录

整理日期：2026-10-31。范围：本目录的源码、文档、示例图片、由其生成的 GitHub 源码 ZIP，以及同时单独提供的公开重建 APK。原开发目录和设备运行数据不属于上传内容。

## 已采取的处理

| 项目 | 处理方式 |
| --- | --- |
| 本机身份与路径 | 不带入含个人目录和下载文件路径的内部审查资料，重新编写公开文档；文档和图片引用使用相对路径 |
| Git 元数据 | 不复制原 `.git`，不带入作者邮箱、remote、凭据缓存或旧提交历史 |
| 认证与签名 | 排除真实本机配置、私钥、keystore、环境文件和运行连接数据；只保留无有效凭据的签名配置示例 |
| 构建与研究资料 | 排除 SDK/JDK、构建缓存、设备数据、内部日志、APK、旧源码 ZIP 及无关研究产物 |
| 示例账号与地址 | 保留明确的演示域名与测试账号；测试节点地址改为文档示例地址 `192.0.2.10` |
| 截图测试路径 | 中文字体和图标字体由环境变量提供，不把开发机器字体路径写入测试 |
| 图片 | 只选六张合成数据图片，核对可见账号、域名、作业与节点；检查全部 11 个 PNG，并无损清除三个 Web 图标的附加文本元数据，像素数据保持一致 |
| 旧 APK 元数据 | 发现插件注册器编译 URI 带有构建机路径；不复用旧 APK，改用中性位置重建，调试符号留在被忽略的本地目录 |
| 后续误提交 | 增补 `.gitignore`，覆盖环境文件、密钥、签名配置、fixture 数据、缓存、安装包和压缩包；Gradle Wrapper 保持可提交 |

## 有意保留的测试内容

`researcher`、`tester`、`demo`、`/home/demo`、`/home/tester`、`*.example.org` 和 `127.0.0.1` 都是演示或回环测试资料，不是真实集群身份。

`test/key_file_test.dart` 中的私钥文本只有格式头、`fixture` 占位符或不完整内容，不含可用于认证的私钥。界面代码中的私钥格式提示同样只是提示字符串。测试服务运行时会生成一次性密钥，这些运行结果不在源码包中。

自动扫描应结合这些上下文判断，不能把所有 `password` 字段名或私钥格式标题当成真实泄露，也不能因为命中数量为零就保证未来新增内容安全。
